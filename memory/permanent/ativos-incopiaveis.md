# O que sobra quando copiam a ideia

1. **Catalisador físico** — endereço no shopping. Presença é moat; nenhum concorrente
   puramente digital replica densidade local.
2. **Lastro acumulado** — rastro verificável que só engorda e é portável. Quanto maior,
   mais caro de reconstruir em outro lugar.
3. **Prova co-assinada** — reputação testemunhada pela marca, não alegada. Dado
   proprietário que cresce por transação.
4. **Rede coordenada** — efeitos de rede locais; densidade por praça vira barreira.

**Por quê:** é o que responde ao risco de desintermediação. Fechado o primeiro trabalho,
as partes poderiam sair da plataforma — mas sair é perder o histórico verificável.

**Como aplicar:** o board 05 (espiral) existe para tornar o item 2 visível. Acúmulo é o
argumento, não repetição.
