# Inventário vs. Tese Estratégica v1

Existem dois enquadramentos no material, e eles descrevem **empresas diferentes**:

| | Inventário Intelectual | Tese Estratégica v1 |
|---|---|---|
| O que é | camada de inteligência que transforma problemas em soluções | infraestrutura de reputação verificável |
| Entrada | problema genérico de negócio | contratar criatividade sem prova |
| Público | empresas | varejo + profissional + creator, numa praça |
| IA | FeelMind, Creative Intelligence, matching | quarentena explícita |
| Moat | inteligência acumulada | espaço físico + lastro co-assinado + rede local |

**Decidido (D-14):** a Tese v1 vence. O Inventário é arquivo histórico (D-13).

**Sinais de que a tese antiga está voltando:** apareceu "FeelMind" como capacidade
presente; a entrada virou "problema genérico de negócio"; apareceu "camada cognitiva";
a peça fala com "empresas" em vez de varejo local e profissional criativo.

**Como aplicar:** ao ler `docs/planejamento/` ou o Inventário, tratar como arquivo. São
bons documentos — de outra fase. Não são lei.
