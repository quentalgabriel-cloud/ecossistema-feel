# A categoria

"Plataforma de creator" compete com TikTok. "Agência" compete com agências.
"Marketplace" compete com Fiverr. Todas são guerra de preço e alcance.

A saída é nomear e possuir um espaço vazio: **infraestrutura de reputação verificável
para a economia criativa**.

**Por quê:** nomear o problema (a reputação não-verificável) é possuir a resposta. Quem
cria a categoria define as regras. O eixo novo é confiança verificável — onde ninguém
compete ainda.

**Como aplicar:** nunca usar "plataforma", "marketplace", "hub" ou "clube" como
autodescrição. Cada rótulo atrai o concorrente errado.
