# Boards de referência

Os 4 infográficos já gerados são a **fonte de verdade da linguagem visual da FEEL**
(decisão D-02). Eles precisam estar aqui em alta resolução para dois usos:

1. **Amostragem de cor** — os hexes em `docs/01-linguagem/LINGUAGEM.md` são leitura
   visual, não medição. A Fase 1 os corrige amostrando destes arquivos.
2. **Critério de aceite** — o export de `npm run export` é comparado lado a lado
   com estes PNGs. Fidelidade tipográfica é o critério.
